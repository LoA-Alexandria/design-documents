# Officer chat

Status: draft.

The master and officers can read and write a separate officer chat. Members who are not officers cannot read officer chat.

This file owns that boundary. Alliance officer chat uses the same rule for officers of either guild. See [Alliances](alliances.md). A site admin can act as the guild's master, including in officer chat, from the site rank rather than from a guild post. See [users](../../product/users.md).

## Done when

- Only the master and officers can read and write officer chat.
- A member who is not an officer cannot read officer chat.
