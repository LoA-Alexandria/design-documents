# Publish

Status: draft.

An Editor publishes only when they have the publish permission. That permission is not a separate site rank. A site admin always has it, and can grant or revoke it on an Editor. Publishing makes the piece readable by everyone, including anonymous users. Publishing again with the same identity replaces the live piece. Unpublished drafts stay invisible to readers. See [Published pieces](../reading/published-pieces.md) and [Users](../../product/users.md).

The proof of concept used two ranks (guide writer and manager). This product keeps one Editor rank and treats “may publish” as a permission on that rank. Recorded as closed in [scope](../../product/scope.md).

Sharing a published piece into Discord as a formatted post is on the proof of concept and is not part of this feature yet. See [scope](../../product/scope.md).

## Done when

- An Editor with the publish permission, or a site admin, can make a piece public, and anonymous readers then see it.
- An Editor without the publish permission cannot make a piece public.
- A Normal user cannot publish.
- A site admin can grant or revoke the publish permission on an Editor.
- Publishing again with the same identity replaces the live piece.
