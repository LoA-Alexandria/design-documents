# Publish

Status: draft.

An Editor publishes only when they have the publish permission. A site admin always has that permission. Publishing makes the piece readable by everyone, including anonymous users. Publishing again with the same identity replaces the live piece. Unpublished drafts stay invisible to readers. See [Published pieces](../reading/published-pieces.md).

## Open decision

This spec uses one Editor rank, plus a permission to publish. The proof of concept uses two ranks (guide writer and manager). The single rank is not confirmed. See open decision 1 in [scope](../../product/scope.md).

Sharing a published piece into Discord as a formatted post is on the proof of concept and is not part of this feature yet. See [scope](../../product/scope.md).

## Done when

- An Editor with the publish permission, or a site admin, can make a piece public, and anonymous readers then see it.
- An Editor without the publish permission cannot make a piece public.
- A Normal user cannot publish.
- Publishing again with the same identity replaces the live piece.
