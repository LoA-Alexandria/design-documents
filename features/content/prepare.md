# Prepare

Status: draft.

An Editor prepares news, guides, and event write-ups, including their translations. A site admin can prepare as well. A Normal user cannot.

News needs no category. Guides and event write-ups need a category and a position in that category. Whether event categories match the game is still open. See [Published pieces](../reading/published-pieces.md).

Preparing a piece does not make it public. Who may publish is defined in [Publish](publish.md).

## Done when

- An Editor without the publish permission can prepare a piece and cannot make it public.
- A Normal user cannot prepare.
