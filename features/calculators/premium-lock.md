# Premium lock

Status: draft.

Some tools are limited to members with active Premium. A Premium tool tells an anonymous user to sign in, and tells a signed-in member without Premium that the tool is part of Premium. Premium calculators ship with Premium, when the lock is real. See [scope](../../product/scope.md) and [Entitlement](../premium/entitlement.md).

This file owns the lock. Other specs link here instead of restating it. What active Premium is, and how a member gets it, are defined in [Entitlement](../premium/entitlement.md) and [Claims](../premium/claims.md).

## Done when

- A Premium tool stays locked until the signed-in member has active Premium.
- An anonymous user is told to sign in, and a signed-in member without Premium is told that the tool is part of Premium.
