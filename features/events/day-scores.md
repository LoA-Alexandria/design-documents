# Day scores

Status: draft.

Officers, the master, and a site admin run a guild's event plan. Members follow it. Officers turn an event on and off. Turning an event off clears that event's plan — targets, scores, pledges, painted territory, and its alliance — after the officer confirms, so the next match starts empty.

For a scoreboard event, officers record day scores and members record what they will invest at the end. Members see the plan for the active event. A Normal user who is only a member cannot change the shared plan.

Siege maps and territory painting are defined in [Siege board](siege-board.md) and [Territory board](territory-board.md). Ending an event also clears its alliance, as [Alliances](../guilds/alliances.md) describes the alliance itself.

## Done when

- An officer can turn an event on, and members of that guild can see the plan.
- A Normal user who is only a member cannot change the shared plan.
- Officers can record day scores, and members can record what they will invest at the end.
- Ending an event, after confirmation, removes that event's plan and alliance.
