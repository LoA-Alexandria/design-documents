# Siege board

Status: draft.

For an event that is fought over camps, the plan is a map. Officers mark the guild's base, put targets in an order, split Military Tokens (horns) across targets so the shares add to 100 percent, and say whether Draupnir Rings hit one camp or the whole field. Each member marks which targets they will attack. The map shows the order, the share, whether rings land there, and how many members attack it. The shares are visibly wrong when they do not add to 100 percent.

Members do not type an attack total. They only choose where their attacks go.

Other siege events allow up to five partner guilds. Offering an event alliance requires this base marker and is defined in [Alliances](../guilds/alliances.md). Turning the event off clears the siege plan, as defined in [Day scores](day-scores.md).

## Done when

- On a siege map, horn shares are visible and are flagged when they do not total 100 percent.
- Each member can set only their own attack targets, and does not type an attack total.
- Officers can mark the guild's base, order targets, and say whether Draupnir Rings hit one camp or the whole field.
