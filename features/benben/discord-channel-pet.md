# Discord channel pet

Status: draft.

A Discord channel has its own Benben, separate from the community pet. A member opens that channel's Benben from Discord, and the channel keeps a single status message that updates when someone takes care of it.

Care from Discord uses the same three daily actions and the same rules as the community pet. Those rules are defined in [Community pet](community-pet.md). This file does not restate them.

## Done when

- Each Discord channel that opens Benben has its own needs and journey, and one status message in that channel.
- Care from Discord spends the same three daily actions, under the same rules as the community pet.
