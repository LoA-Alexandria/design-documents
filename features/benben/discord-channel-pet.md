# Benben on Discord

Status: draft.

Discord opens the one community Benben. A channel does not get a pet of its own. The channel keeps a single status message, and that message shows the shared pet. It updates when someone takes care of Benben.

## Done when

- Opening Benben from any channel shows the same needs and journey as the site.
- A channel that shows Benben keeps one status message for that shared pet.
