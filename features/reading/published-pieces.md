# Published pieces

Status: draft.

Anyone, including an anonymous user, can read what staff have published: news, guides, and event write-ups. News has no category and is listed newest first. Guides and event write-ups are grouped by category and ordered by the position chosen at publish time. See [Publish](../content/publish.md).

Language URLs, fallback to English, and how numbers and dates are shown are defined in [Language URLs](language-urls.md).

## Guide categories

The same categories as on game-calculators, in this order:

- Core elements
- Layouts
- Buildings
- Tier lists
- Tips and tricks
- Goddess
- Events
- Grand Voyage

## Event categories

The same categories as in the game:

- Main event (blue)
- Routine Event (orange)
- Ranking Challenge (red)

## Done when

- An anonymous reader can open a published news item, guide, and event write-up without signing in.
- News has no category and is listed newest first.
- A guide is in one of the guide categories above, at the position chosen when it was published.
- An event write-up is in one of the three game categories above, at the position chosen when it was published.
- Unpublished drafts are invisible to readers.
