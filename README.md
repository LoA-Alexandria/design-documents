# Community site — product spec

This spec describes the community site to build from scratch for Pop Epoch players maintained by LoA Alexandria. It records what people already do on the `game-calculators` proof of concept, written as jobs. It does not describe pages, routes, or a technical design yet, but should have it later.

`game-calculators` is evidence for these jobs. It is not the architecture to copy.

## How to read it

1. [Users](users.md) — who can act, and which attributes combine.
2. [Jobs](jobs.md) — what each person is trying to get done, and when that job is complete.
3. [Scope](scope.md) — which jobs belong in the product, a suggested build order, and decisions still open.

Later documents (software design, working rules for agents) are intentionally absent. They come after this product spec is agreed.
